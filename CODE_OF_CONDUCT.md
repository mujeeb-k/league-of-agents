# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, be respectful of different views and experience, give and take feedback gracefully, and focus on what's best for the people using and building League of Agents. Harassment, insults and personal attacks are not tolerated, in issues, pull requests, discussions or anywhere else you speak for the project.

## Reporting

If someone's behaviour worries you, tell the maintainers privately: use **Report a vulnerability** on the repository's **Security** tab and start the title with "Conduct". Reports are read only by the maintainers and kept confidential. The maintainers decide on the response, from a private word to a permanent ban, following the Covenant's enforcement guidelines.
