你的代码

League of Agents never uploads your code anywhere. Your code goes only to the agent you authorized.

League of Agents 从不把你的代码上传到任何地方。你的代码只会交给你授权的代理。

League of Agents 通过桥接程序读取你的仓库，这是一个在你自己电脑上运行的小程序。桥接程序只与你电脑上的 127.0.0.1 通信。本页面 leagueofagents.dev 直接从你的浏览器与这个桥接程序通信。你的代码、提示词、运行和快照只在你的浏览器和你的电脑之间传递。League of Agents 没有任何接收代码的服务器。

本站统计什么

leagueofagents.dev 使用 Vercel Web Analytics 统计页面浏览量，以了解有多少人访问、来自哪里。每次页面浏览，它可能记录：

  • 时间，以及页面路径（例如 /），不含 ? 或 # 之后的任何内容，因此连接你的桥接程序的链接永远不会被发送；
  • 链接到该页面的网站；
  • 根据请求推断出的国家、地区和城市；
  • 操作系统、浏览器和设备类型。

这也包括 leagueofagents.dev 上的应用，League of Agents 在 Chrome、Edge、Brave 和 Arc 中打开它并连接到你的仓库：它的页面浏览以同样方式统计，绝不统计你的代码、你的提示词或 # 之后的任何内容。

它不使用 cookie。访客通过请求的哈希值来区分，该哈希值在 24 小时后丢弃，数字也只以汇总形式查看。桥接程序在你电脑上提供的应用不做任何统计。

你的浏览器保存什么

你的浏览器会把你连接过的桥接程序（它的端口和令牌）以及你对面板、主题和语言的选择保存在它自己的存储中，留在你的设备上，以便刷新后重新连接。断开连接会删除这个连接。

你的编码代理

当你运行 Claude Code、Codex、Cursor 或其他代理时，它会按照其服务商的条款，把你的提示词和代码发送给它自己的服务商。League of Agents 在你的电脑上启动代理，并记录它在那里做出的改动。它把你的提示词和所选的文件或行（以路径和行号的形式）交给代理。“更新依赖它的内容”还会把你这次改动的 diff 放进提示词。

安装

桥接程序来自 npm 注册表，受 npm 自身条款约束。
